# Office UI shell

Simple functional shell — not the vision mockup.

```mermaid
flowchart LR
    UI[apps/office-ui]
    API[FastAPI /agents]
    DISK[office/ desks]
    UI -->|POST create| API --> DISK
    UI -->|DELETE remove| API
    UI -->|GET list| API
```

| Nav | Status |
| --- | --- |
| Team | List desks + chat + Create + Remove |
| Office | Front-desk Q&A |
| Memory | Gold + team OKF + Export OKF |
| Approvals | One action-card board (propose / Accept / Reject) |
| Analytics / Connect / Settings | Stub |

Served by orchestrator: `GET /` → `index.html`, assets under `/assets/*`.  
Path: `OFFICE_UI_PATH` (local `./apps/office-ui`, Docker `/ui`).
